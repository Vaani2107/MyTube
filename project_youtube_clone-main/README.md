# MyTube — Premium Video & Media Streaming Application

A highly responsive, modern video streaming platform built using **React JS** and **Material UI v5**. Powered by a centralized asynchronous API layer, MyTube allows users to explore trending content across diverse categories, search for specific videos, enjoy seamless media playback, and explore deep-dive creator channel metrics in an immersive dark-mode layout.

---

## 🚀 Core Features

*   **Dynamic Category Feeds:** A state-driven sidebar allowing users to switch between genres (Tech, Coding, Music, Gaming) with instant, zero-refresh feed updates.
*   **Contextual Search Engine:** A robust search bar component that captures user queries, updates client-side routing, and fetches real-time media payloads.
*   **Seamless Media Playback:** Integrated custom video player controls utilizing `react-player` for high-fidelity streaming and uninterrupted playback.
*   **Creator Profile Dashboards:** Comprehensive channel detail views showcasing subscriber metrics, official banners, and individual video uploads.
*   **Responsive UI/UX Build:** Developed with a strict mobile-first approach using Material UI flexbox and grid breakpoint systems to ensure beautiful rendering on mobile, tablet, and desktop viewports.

---

## 🛠️ Architecture & Tech Stack

*   **Frontend Library:** React.js (v18)
*   **UI Components & Styling:** Material UI (MUI) v5 & Emotion Styled Components
*   **Routing Architecture:** React Router DOM (v6) for single-page application (SPA) routing
*   **Asynchronous Data Layer:** Axios client wrapper for centralized handling of third-party REST API payloads
*   **Media Streaming Engine:** React Player
